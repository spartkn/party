تشغيل المشروع على جهازك:
  node server.js            ثم افتح  http://localhost:3000/invitation/  و  http://localhost:3000/scanner/
مع الذكاء الاصطناعي (اختياري):
  Windows PowerShell:  $env:ANTHROPIC_API_KEY="مفتاحك"; node server.js
  Mac/Linux:           ANTHROPIC_API_KEY=مفتاحك node server.js
النشر على الإنترنت (Render):  Build Command = npm install   |   Start Command = npm start
المفتاح السري SECRET مضبوط مسبقًا بنفس القيمة في ملفي invitation/index.html و scanner/index.html.
